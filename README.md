# スイム大会運営ボード

水泳大会のエントリーから表彰までを、ブラウザだけで運営できる無料ツールです。
`index.html` という1つのファイルだけで動き、サーバーもアカウント登録も要りません。

## できること

| 画面 | 内容（元のExcelとの対応） |
|---|---|
| 本部ボード | いまの種目・予定との遅れ・全種目の入力状況・開催前の確認に加え、申込者数・売上・メダル発注数・クラブ別得点（00_ダッシュボード） |
| 大会設定 | 種目・区分・クラブ、レーンの優先順、1組の最低人数、合同レース、スケジュールの時間、得点（03_大会設定リスト） |
| 個人／リレーエントリー | 入力すると組・レーン・順位・得点・状態を自動計算（01・02） |
| 進行スケジュール | 参加数・組数・所要時間・開始/終了時刻を自動計算（04） |
| プログラム作成・記録入力（組・記録） | 組・レーン順のプログラム。開くと最初の未入力レーンに入力できる状態になり、Enter で次のレーンへ。打ち間違いの可能性がある行は黄色。種目が終わると「次の種目へ」（05・06） |
| 速報 | 区分ごとに 順位→失格→棄権 の順に並べる。記録入力中の種目に自動で切り替わる。大きな文字の表示もある（18） |
| ランキング | 種目×区分の公式順位（08・09） |
| 印刷まとめ | すべての印刷物の一覧・プレビュー・選んで結合印刷（新規） |
| 記録証・賞状 | A4縦（1人1枚）、個人／リレー、絞り込み、範囲指定、1枚テスト印刷、位置の微調整（10〜17） |
| 最優秀・優秀選手 | 表彰者算出マクロ（v4）の選出ルールをそのまま移植。大会結果の1〜3位から自動取り込みもできる |
| 入力チェック | 入力ミスを常時点検し、ワンクリックで修正 |
| データ管理・Excel | バックアップ、復元、今のExcelファイルの読み込み、結果のExcel/CSV書き出し |

計算は元のExcelと同じになるように作り、お手元の2つのファイルで照合しました（個人275件・リレー15件の組とレーン、スケジュール20行の開始・終了時刻がすべて一致）。

## 画面と操作

- 各画面の名前と説明は上部のバーに表示し、画面の中は表や入力に広く使います。
- 操作ボタンはすべて同じ大きさの丸（丸の中はアイコン、名前は丸の下。正式な名前はマウスを乗せると表示）。検索欄・選択欄は丸ボタンの列とは別の列に、同じ高さ・同じ形でそろえています。PC・タブレット向け（スマホ専用画面はありません）。どの画面も、丸いボタンの列は左上から同じ順番で並び、画面の幅が変わっても位置は変わりません（入りきらないときは横にすべらせます）。判定（棄権・失格・対象外）や前・次も丸です。
- ボタンは白い面とはっきりした縁・文字で表示します。切り替えのタブは iOS と同じく、灰色の帯の上の白いピルで選んでいる項目を示します。

- 左上（または右上）の三本線で画面の切り替え一覧を開きます。一覧の上で「左に表示／右に表示」と「常に表示」を選べます（パソコンなど幅の広い画面で常に表示できます。設定は端末ごとに保存）。
- 切り替えボタンは iOS の液体ガラスと同じ動きです。押している間だけ透明なガラスがふくらんで指（カーソル）の位置に付き、下の文字やアイコンが少し拡大して見えます。押している間はバーの外へ指が出ても追従し、離すと一番近い項目に短く吸い付いて止まります。押していないときは動きません。表は画面の中でスクロールするので、ページ全体はほとんど動きません。
- 上部の丸アイコンの列で、どの画面にもすぐ移れます（簡易アクセス）。少し押し続ける（マウスなら少し乗せる）と、どの画面かの説明が出ます。押したまま横へなぞると、ガラスが付いてきて、離した所の画面が開きます。
- ガラスが滑る動きは「選ぶ」ボタン（切り替えタブ・簡易アクセス・画面一覧・組のタブ）だけです。「前」「次」「印刷」のような1つだけのボタンは、押している間だけ少し沈み、位置は動きません。
- 入力欄に打ちかけのまま別のボタンを押しても、打った内容は確定され、ボタンも1回で反応します。

### プログラム作成・記録入力

- 表は画面の幅に合わせて縮み、横にスライドしなくても「レーン・氏名とチーム・区分と申込記録・公式タイム・判定・順位」がすべて見えて入力できます。スマホなど細い画面では、1人を2段にして全部を表示します。
- その種目の全組が画面に入りきらないときは、1組ずつ表示して上に「第1組・第2組…」のタブを出します。Enter で最後のレーンまで入れると、自動で次の組へ進みます。
- 種目の選択欄は幅が一定なので、種目を切り替えても「次 →」ボタンの位置は動きません。
- 印刷プレビューを横に出していても、全部の列が見えます。名前やチーム名は「…」で省略せず、長いときは文字を少し小さくし、それでも入らなければ2行にします（リレーの泳者は名前の途中では改行しません）。

### タブレットで計時して公式タイムに入れる（QRコード）

- タブレット（スマホでも可）で、このアプリのアドレスの最後に `?timer` を付けて開くと「スイム計時」の画面になります（例: `https://swim-swim.github.io/swim-meet-board/?timer`）。パソコンの「組・記録」→「タブレットから読み込む」→「タブレットで計測画面を開くには」のQRをタブレットのカメラで読んでも開けます。
- タブレットでは「競技No.」と「組」を合わせ、ピストルで「スタート」、各レーンのゴールのタッチでそのレーンのボタンを押します。押した瞬間のタイムが 1/100 秒で入ります（手動計時なので押す人の反応の分ずれます）。押し間違いは「取消」、フライングは「スタートを取り消す」（どちらも2回押し）。
- 組が終わったら「QRを表示」。パソコンの「タブレットから読み込む」でカメラに向けると、種目・組・レーンごとの選手名と、いまの公式タイム・タブレットのタイムが並んだ確認画面が出ます。印を付けたレーンだけ「公式タイムに入れる」で入ります（もう入っているレーンは「上書き」の印が付き、最初は選ばれていません）。入れた内容は変更履歴に残り、元に戻すこともできます。
- 1台で全レーンでも、レーンごとに1台ずつでも使えます（QRには計ったレーンだけが入ります）。使うレーンはタブレットの「設定」で決めます。前の組のQRは「これまでの組」からもう一度出せます。
- カメラが使えないときは、QRの下に出ているコード（`SMB1|…`）を確認画面の欄に入力しても読み込めます。
- インターネットは使いません。タブレットには選手名などのデータを送らず、QRには競技No.・組・レーン・タイムだけが入ります。カメラの映像もパソコンの中だけで読み取ります。
- 当日モード中でも入れられます。大会確定中は入れられません。

### 組・レーンの入れ替え（ドラッグ＆ドロップ）

- プログラム作成・記録入力画面の「組・レーンを入れ替え」で、その種目の全組をレーンごとに並べて表示します。
- 入れ替え画面では、ピンチ（トラックパッド・タッチ画面）や Ctrl＋マウスホイールで、1行に並べる組の数を増やしたり減らしたりできます（広げると大きく少なく、つまむと小さく多く）。1組の幅が狭くなりすぎない所で止まり、選手名・チーム名は省略せずに折り返して表示します。
- 選手を別のレーンへドラッグすると入れ替わり、空きレーンへ落とすと移動します。いちばん下の「新しい組」へ入れると組が増え、空になった組は自動で詰めます。スマホ・タブレットは少し長押ししてから動かします（ふつうになぞるとスクロール）。タップで選んで行き先をタップしても同じです。
- 入れ替えるたびに「元に戻す」が出ます。「自動の並びに戻す」で申込記録順の自動割り当てに戻せます。
- 入れ替えた種目は全員の位置を固定するので、後から申込が増えても他の人は動きません。新しい人は空いているレーンに入ります（固定した人と重なる場合は空きレーンへ自動でずらして、画面でお知らせします）。
- 当日モード中は入れ替えできません（記録の入力はできます）。
- 説明文は1行に畳んであり、押すと全文が出ます。
- リレーは各チームの横の人のボタン（泳者の追加・交代）で、欠場や人数不足のときに泳者を検索して入れられます（同じクラブの選手が上に出ます。一覧にいない名前もそのまま入れられます）。4人そろっていないチームは「3/4人」と黄色で表示します。当日モード中でも使えます。
- 「ほかの種目も並べる」で2つの種目を左右に並べ（組は縦）、片方の選手をもう片方へ移すか「合同にする」を押すと、合同種目の名前を自動で決めるポップアップが出ます。合同にしても記録証・賞状・順位・優秀選手は各自のエントリー種目のままで、画面には「合同」の印が付きます（印刷物には出ません）。合同で0名になった種目も進行スケジュールに並べられます（「0名・合同へ」と表示）。

## 印刷プレビューと印刷まとめ

- スケジュール・記録入力・速報・ランキング・記録証・表彰の各画面の右側に、A4の印刷プレビューを常に表示します（右上の × で隠し、「印刷プレビューを表示」で戻せます。設定は端末ごとに保存）。
- プレビューはピンチ（トラックパッド・タッチ画面）や Ctrl＋マウスホイールで、その場で拡大・縮小できます（右上の「%」を押すと元の大きさ）。ページをダブルクリック（ダブルタップ）すると、その1枚を画面いっぱいに大きく表示します（‹ › で前後のページ、ピンチで拡大、Esc で閉じる）。
- 記録証・賞状の画面: プレビューはピンチ／Ctrl＋ホイールで拡大・縮小、ダブルクリックで 2倍⇔元の大きさ。「文言」タブの「手書き用（名前・記録を空欄）」で名前・クラブ・順位・記録を下線の空欄にして印刷、「順位を印刷しない」で順位の行を省けます（記録証・賞状それぞれ、A4・A5 どちらでも）。
- 印刷画面を閉じると、その印刷物に「✓ 印刷済み（日時）」が付きます（印刷まとめの一覧と、各画面の印刷ボタンの ✓）。取り消した場合も付くので、印を押せば手で外せます。印刷していない物にも手で付けられます。記録証を一部の人だけ印刷したときは「一部 3/96」のように出ます。
- 「印刷まとめ」画面に、大会で使う印刷物（スケジュール、各種目のプログラム、速報、ランキング、表彰ボード、記録証・賞状）をすべて並べています。「見る」でその印刷物だけをプレビューし、チェックを入れたものを上から順に1つの印刷にまとめて出せます。

## 記録証の対象

- 「記録証・賞状」画面の「賞状の対象者（n位以内）には記録証を出さない」にチェックを入れると、賞状をもらう選手を記録証の印刷から除きます（印刷まとめも同じ）。

## 記録証・賞状のフレーム

- 「記録証・賞状」画面の設定で、フレームを付けて印刷できます（金・伝統／金・シンプル／水泳（波とコースロープ）／銀・モダン）。ベクター画像なので拡大しても粗くなりません。
- 「記録証と賞状で同じフレームにする」を外すと、記録証と賞状で別のデザインにできます。種類ごとに「フレームを付けて印刷する」で表示・非表示を切り替えられます（フレーム入りの用紙に印刷するときは非表示に）。
- 自分の画像（PNG・JPEG、A4縦・2000ピクセル以上がおすすめ）もフレームとして使えます。画像はその端末のブラウザにだけ保存され、公開サイトやバックアップファイルには入りません。
- 証書は用紙の印刷できる範囲いっぱいに、フレームと文字の配置をそろえて印刷します（プリンターの余白があっても白紙ページは出ません）。

## 1部・2部

- どのパソコン（Windows のレッツノートなど・Mac）でも同じ並びの画面になります。画面の幅に合わせて全体を自動で拡大・縮小します（幅 1280 の画面を基準）。大きさは左上の三本線のメニュー「大きさ」で 自動／小／大／等倍 を選べます。印刷はいつも等倍です。
- 本部ボードの「判定」で、棄権・失格・対象外の数がすぐ分かります。押すと 1部・2部・合算（完泳・未入力も、個人とリレーの内訳つき）を表示します。
- 上部のバーの「1部／2部」で、それぞれ別のデータとして保存・切り替えできます（Excelの取り込み・バックアップも、いま選んでいる部に対して行います）。

## データ管理

- このブラウザ内の自動バックアップ（控え）は、不要なものを選んで削除できます。今のデータやファイルに書き出したバックアップは消えません。
- 控えには題名（例: 「1部 終了時」）を付けられます。題名を付けた控えは自動では消えません。データ管理の画面は1画面で全部見られます。
- 「データ管理」の右の欄「変更履歴」に、最初のプログラム作成から大会終了までの変更（だれの何を何から何へ）・印刷・ロック・復元などが自動で残ります。元に戻しても記録は消えません。検索・CSV書き出しができ、バックアップのファイルにも入ります。

## 氏名とフリガナ

- 氏名は個人もリレーの泳者も「苗字　名前　ミョウジ　ナマエ」の形です（空白は半角でも全角でも可）。プログラム・記録入力・速報・ランキングの画面とプログラムの印刷では、漢字の上にフリガナを小さく載せて表示します。印刷物（プログラム・速報・ランキング・表彰ボード・記録証・賞状）でも、名前の上にフリガナを小さく印刷します（記録証・賞状は「名前の上にフリガナを印刷する」で切り替え）。表の列は幅をそろえてあり、組・区分が変わってもクラブ名などの位置がずれません。
- フリガナの表記は大会設定の「フリガナの表記」でカタカナ／ひらがなを選べます。切り替えると入力済みのフリガナもすべてそろえます。手入力やExcelの読み込みで違う表記（半角カナを含む）で入っても、自動で設定の表記に直します。

## エントリー用Excel（配布 → 記入 → 締め切り後に読み込み）

1. 「データ管理」画面のいちばん上「エントリー受付」の ①「エントリー用Excelを作る」で、全チーム共通・チームごと・特定チーム用のExcelを作ります（オフラインでも作れます）。
2. 各チームに配ります。チーム名・区分・種目は ▼ から選ぶ形で、氏名は姓・名・セイ・メイに分けて書くので、打ち間違いが起きにくくなっています。リレーは泳者4人それぞれに「氏名」と「フリガナ」の欄があります。フリガナの見出しは大会設定の表記（カタカナ／ひらがな）に合わせます。記入方法シートに締め切りと提出先も載ります。
3. 締め切り後、返ってきたファイルを同じ所の ②「記入済みExcelを読み込む」でまとめて選びます（複数ファイル可）。読み込む前に件数と確認が必要な行が表示され、「追加」「そのチームだけ置き換え」「すべて置き換え」を選べます。フリガナはカタカナ・ひらがな・半角カナのどれで書かれていても大会設定の表記に直し、全角のタイムは半角に直して取り込みます。以前に配った形（リレーの泳者が氏名だけ）のファイルもそのまま読み込めます。

## 印刷

プログラムは1枚に4組ずつ、どのページも同じ行の高さ・文字の大きさで印刷します。各組の見出しの下に「レーン」とレーン番号が並びます。4組に満たないページは「空白」か「次の種目を詰める」を選べます（プログラム画面の印刷の設定）。印刷の形を2つから選べます（プログラム画面の「印刷:」の欄）。
- 手書き用: 記録と順位の欄が空の記入枠になります。大会中、審判がタイムを手書きします。
- 記録入り: 入力した公式タイムと順位（1〜3位は金・銀・銅）が入ります。大会後の記録として配れます。「印刷まとめ」には、記録が入った種目の「プログラム（記録入り）」も並びます。
用紙に余白が大きく残るときは、行の高さを広げて1枚を使い切ります。

すべての印刷物は A4 縦で、用紙の中央に 196×266mm の大きさで印刷します（Chrome・Edge はそのまま中央に、Safari・iPhone・iPad・Android がそれぞれ余白やヘッダ・フッタを付けても、切れたり2枚に分かれたりしません）。印刷まとめでは「記録証すべて」「賞状すべて」でまとめて選べます。すべての印刷物は A4 縦 1枚に収まります（入りきらないときは自動で縮小。スケジュールなどは2段組みも使いますが、プログラムは必ず組を上から縦に並べます）。記録証・賞状は1人A4 1枚（記録証・賞状の画面の「A4 縦／A5 横」で切り替え。A5 横は専用のフレーム・文字配置で、文言と印刷位置も A5 用に別に決められます）で、プリンターの余白があっても白紙ページは出ません。
白地に細い線と文字だけのシンプルな構成です。題名を大きく、1〜3位は金・銀・銅の丸、レーン番号は丸囲みで示します。表の文字も見出しも記録証の各行も改行させず、入りきらないときは自動で縮めます（大きくはみ出すときは2段組み）。

## アプリとして追加する

- iPhone / iPad（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」
- パソコン（Chrome / Edge）: アドレスバー右端のインストールボタン、またはメニュー →「アプリをインストール」
- Mac（Safari）: ファイル →「Dockに追加」

一度開けば、電波の悪いプールでもオフラインで起動できます。

## ミスやトラブルへの備え

| 起きること | アプリの対応 |
|---|---|
| 間違えて消した・変えた | 上部の ↶（Ctrl+Z）で60回分まで戻せる。削除直後は「元に戻す」ボタンも出る |
| もっと前の状態に戻したい | 5分ごと・大きな操作の前に自動で控えを残す（データ管理 → 自動バックアップ） |
| ブラウザが落ちた・閉じた | 入力のたびに自動保存しているので、開き直せば続きから |
| パソコンの故障・履歴削除 | バックアップファイル（.json）を書き出しておけば、別のパソコンでも復元できる。しばらく書き出していないと画面で知らせる |
| 保存できない（容量不足など） | 赤い警告を出して、すぐ書き出せるボタンを表示 |
| 当日に設定をうっかり変える | 「当日モード」で設定・エントリーをロック。記録入力だけはできる |
| 大会後に記録を書き換えてしまう | 上部の「大会確定」で記録・エントリー・設定をすべてロック（見る・印刷・書き出しはできる）。解除はパスワード |
| タイムの打ち間違い・全角入力 | 入力欄の下に読み取った結果を表示。読めない値は赤。全角は半角に直して保存 |
| 極端なタイム | エントリータイムや同じ組の中央値から大きく外れると注意を表示 |
| 二重エントリー・リレー泳者の重複 | エラーとして表示し、該当行へ移動できる |
| リストにない種目・区分・クラブ | 警告し、ワンクリックでリストへ追加できる |
| 種目がスケジュールにない／2回入っている | エラー・注意として表示し、まとめて追加できる |
| 名前を変えたい | 「名前の一括変更」でエントリー・スケジュール・合同レースもまとめて書き換え |
| 2つのタブで同時に開いた | 別タブの変更を自動で読み込み、知らせる |
| 印刷位置が用紙とずれる | 文字の大きさ・上下左右のずれを mm 単位で調整。1枚だけテスト印刷できる |
| 並べ替え・絞り込みで計算が崩れる | 起きない（行ごとに識別番号で管理しているため） |

## 動作確認

- Safari（macOS・iPhone・iPad と同じ WebKit）と Chrome（Android・Windows・Mac・Edge と同じ仕組み）で確認しています。
- 画面の幅 320px（小さいスマホ）〜1920px（大きいPC）、スマホの横向き、iPad の縦・横で、全画面の表示崩れ・はみ出しがないことを確認しています。
- iOS 15 以前など古いブラウザでも崩れないよう、新しい表示機能には代わりの表示を用意しています。iPhone では記録の欄に触れても画面が勝手に拡大されません。

## 使い始め方

1. `index.html` をダブルクリックしてブラウザ（Chrome / Edge / Safari）で開きます。
2. 「データ管理・Excel」→「Excelファイルを読み込む」で、今の大会運営ブック（.xlsx）と表彰者算出ブック（.xlsm）を読み込みます。
3. 「入力チェック」で内容を確認します。

Excelの読み込み・書き出しのときだけ、表計算ライブラリ（SheetJS）を初回にインターネットから読み込みます。それ以外はオフラインで動きます。

## 元のExcelと変えた点

- **スケジュールの参加数・組数**: 元の式は、合同レースに回った選手を元の種目にも数えていました。アプリでは実際に泳ぐレース（プログラム）ごとに数えます。合同レースを使わない場合の結果は同じです。
- **200M 種目**: 1組あたりの時間を別に設定できるようにしました（元は50Mと同じ扱い）。
- **点を打たずに4〜6桁で入れたタイム**: 下2桁を1/100秒として読みます（2534 → 25.34、10530 → 1:05.30）。以前は 2534 を 25分34秒と読んでいました。
- **「132.22」のような3桁の数字**: 元の2つのファイルで読み方が違いました（運営ブックは132.22秒、表彰マクロは1分32秒22）。アプリの既定は「1分32秒22」で、大会設定で切り替えられます。どちらの場合も入力欄の下に読み取り結果が出ます。
- **レーンの割り当て**: 既定は元のExcelと同じ（組の中で遅い順に優先レーン①から）。大会設定で「速い順に優先レーン」にも変えられます。
- **証書の枚数上限**: 元の500枚・50枚の上限はありません。
- **用紙**: 印刷物はすべてA4縦に統一しました（B5横は廃止）。
